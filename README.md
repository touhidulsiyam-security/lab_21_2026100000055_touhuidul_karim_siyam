## 1. What is Version Control?
*Version Control* is a system that records changes to a file or set of files over time so that you can recall specific versions later.

## 2. What is Git?
**Git** is a free and open-source distributed local version control system designed to handle everything from small to very large projects with speed and efficiency.

## 3. What is GitHub?
**GitHub** is a cloud-based hosting service that lets developers store, manage, and track their Git repositories online using a web interface.

## 4. What is Git Bash?
**Git Bash** is an application for Windows environments that provides an emulation layer for a Git command-line interface (CLI).

## 5. What are the Parts of GitHub?
- **Repository:** A storage space where your project files live.
- **Commit:** A saved snapshot of your project's changes.
- **Branch:** An independent line of development.
- **Pull Request:** A feature to notify others about changes pushed to a branch.
- **Issues:** Tracking items for bugs or task management.

## 6. What are the Stages of Git/GitHub?
1. **Working Directory:** The local folder where you modify files.
2. **Staging Area:** The area where you prepare changes before committing using `git add`.
3. **Local Repository:** The local Git storage where changes are permanently committed using `git commit`.
4. **Remote Repository:** The online GitHub server where code is uploaded using `git push`.
